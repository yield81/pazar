# Пазар

Търсене на продукти по магазини, подготвяне на списъци за пазаруване и следене на разходите.
Работи локално, без интернет, с данни в JSON файлове. Няма външни зависимости.

## С какво помага

- **Търсене и сравнение** — намира продукт по име (кирилица или латиница) и показва цените
  в различните магазини, подредени от най-евтината.
- **Списъци за пазаруване** — добавяш продукти и количества, а системата ги разпределя
  по магазини и оценява разхода.
- **Покупки и разходи** — записваш реалната цена при покупка и получаваш отчети
  по месец, магазин и категория, със или без бюджет.

## Уеб версия (за телефон и компютър)

`web/index.html` е самостоятелен файл — един HTML с вграден CSS и JavaScript, без интернет
и без сървър. Съдържа демо данните (същите 32 продукта) и работи в браузъра.

**Вариант 1 — локален файл:** отвори `web/index.html` с браузър (на телефон: свали файла
и го отвори; на компютър: двоен клик).

**Вариант 2 — локален сървър** (ако браузърът не отваря локални файлове):

```bash
cd pazar/web
python3 -m http.server 8000
# отвори http://localhost:8000
```

Данните се пазят в `localStorage` на самия браузър. Бутонът „Демо“ връща примерните
данни, „Изтрий“ изчиства всичко.

### Нови възможности в раздел „Продукти"

- **Категории** — виждаш всички категории с бутони за преименуване (✎) и изтриване (×).
  При изтриване на категория, продуктите й отиват в „Други“.
- **Добавяне на категория** — въведи име в полето „Нова категория“ и натисни „Добави".
- **Добавяне на продукт** — всеки категорий има бутон „+ Добави“, който отваря модален прозорец.
- **Снимка на продукт** — в модала има zona за плъгане (drag & drop) и бутон „Избери файл".
  Снимката се запазва като data URL в `localStorage` (работи офлайн).
- **Редактиране/изтриване на продукт** — всеки продукт има бутони „Редактирай“ и „Изтрий".

За да се променят демо продуктите/категории, редактирай `examples/demo.json` и сглоби отново:

```bash
python3 web/build.py
```

## Бърз старт

```bash
python3 -m pazar demo                 # примерни магазини, продукти и цени
python3 -m pazar search мляко         # търсене и цени по магазини
python3 -m pazar compare мляко "хляб бял"*2 яйца
```

След `demo` всички цени са **примерни** и се обозначават с „⚠“. Замени ги с реални:

```bash
python3 -m pazar price set "Мляко 3% 1 л" Лидл 2.29
```

Пълно преминаване през системата:

```bash
python3 -m pazar list new Седмичен
python3 -m pazar list add мляко*2 хляб яйца
python3 -m pazar list show             # групирано по магазин, с оценка
python3 -m pazar list plan             # разпределя към най-евтините магазини
python3 -m pazar buy --use-estimates   # записва покупка с цените от каталога
python3 -m pazar report --all
python3 -m pazar report --month 2026-03 --html report.html
python3 -m pazar budget set 400
python3 -m pazar budget show
```

## Команди

### Магазини и продукти

| Команда | Какво прави |
|---|---|
| `store add ИМЕ` | добавя магазин |
| `store ls` | списък на магазините с брой цени |
| `product add ИМЕ [--cat КАТЕГОРИЯ] [--unit ЕД] [--kw ДУМИ]` | добавя продукт |
| `product ls` | всички продукти с най-добра цена |

Имената се разпознават и наполовина: `product add "Мляко 3% 1 л"` се намира с `мляко`.

### Цени

| Команда | Какво прави |
|---|---|
| `price set ПРОДУКТ МАГАЗИН ЦЕНА [--date ГГГГ-ММ-ДД] [--note БЕЛЕЖКА]` | записва/обновява цена |
| `price ls [ПРОДУКТ]` | показва цените и източника (примерна/реална) |
| `price del ПРОДУКТ МАГАЗИН` | премахва цена |

Цената е уникална за двойката продукт–магазин; повторно задаване я обновява.

### Търсене и сравнение

```bash
python3 -m pazar search ориз
python3 -m pazar compare мляко "хляб бял"*2 яйца
python3 -m pazar compare --file списък.txt        # по един продукт на ред
python3 -m pazar compare --qty 2 мляко хляб      # еднакво количество
```

Всяка дума в командата е отделен продукт. Имена с интервали се пишат в кавички:
`"хляб бял"`, `"мляко 3% 1 л"`. За много продукти е по-удобно `--file` с по един на ред.

`compare` показва:
- цените на всеки продукт по магазини (най-евтината е с ▶);
- **разпределено** — колко струва всичко, ако всеки продукт се купи от най-евтиния магазин;
- **от един магазин** — най-евтиното място, където се намира всичко.

### Списъци

| Команда | Какво прави |
|---|---|
| `list new ИМЕ` | създава активен списък |
| `list ls` | всички списъци с оценка |
| `list show [СПИСЪК]` | позициите, групирани по магазин |
| `list add ПРОДУКТИ [--list ИМЕ] [--qty N] [--store МАГАЗИН] [--note БЕЛЕЖКА]` | добавя позиции |
| `list rm ПОЗИЦИ [--list ИМЕ]` | маха позиции (име или номер) |
| `list plan [СПИСЪК]` | разпределя всяка позиция към най-евтиния магазин |
| `list store ПОЗИЦИ --store МАГАЗИН` | премества позиции в друг магазин |
| `list export [СПИСЪК] [--file ФАЙЛ]` | изнася CSV шаблон с цени |
| `list close` / `list reopen ID` | затваря / отваря списък |
| `list del ID` | изтрива списък (покупките остават) |

Количеството се пише с `*` или `x`: `мляко*2`, `яйца x 1,5`. Имена с интервали
се слагат в кавички: `list add "хляб бял"*2`.

Ако името не е еднозначно (напр. „хляб“ има бял и ръжен), позицията се добавя,
но без връзка към цена и се показват възможните съвпадения.

### Покупки

```bash
python3 -m pazar buy                                   # списъкът, с цени от каталога
python3 -m pazar buy --store Лидл                      # само позициите за Лидл
python3 -m pazar buy --price "мляко=2.10" --price "хляб=1.20"
python3 -m pazar buy --file prices.csv                 # CSV с реални цени
python3 -m pazar purchase ls [--month 2026-03]
python3 -m pazar purchase show ID
python3 -m pazar purchase del ID
```

CSV файлът има колони `name,unit_price[,store][,qty]`:

```csv
name,unit_price,store,qty
мляко,2.10,Лидл,2
хляб,1.20,Кауфланд,1
```

Позициите се записват в реалния магазин и се отбелязват като купени.
Изтриването на покупка връща позициите като непокупени.

### Отчети и бюджет

```bash
python3 -m pazar report                       # текущият месец
python3 -m pazar report --month 2026-03
python3 -m pazar report --year 2026
python3 -m pazar report --all
python3 -m pazar report --all --html otcet.html
```

Отчетът съдържа обща сума, брой покупки, средна кошница, разходи по магазини,
категории и месеци. HTML версията е с ленти за бюджета.

```bash
python3 -m pazar budget set 400
python3 -m pazar budget show
```

## Данни

Всичко се пази в `data/` до пакета (или в папката от променливата `PAZAR_DATA`):

| Файл | Съдържание |
|---|---|
| `stores.json` | магазини |
| `products.json` | продукти, категории, мерни единици, ключови думи |
| `offers.json` | цени по магазини (цена, дата, източник) |
| `lists.json` | списъци и позиции |
| `purchases.json` | записани покупки |
| `settings.json` | месечен бюджет |

```bash
python3 -m pazar init          # състояние на данните
python3 -m pazar demo --clear  # изтрива всичко и зарежда примерни данни
```

## Тестове

```bash
python3 -m unittest discover -s tests -v
```

Покрити са: нормализация и търсене, сравнение по магазини, списъци, цени,
запис и изтриване на покупки, отчети и пълен преминаване през командния интерфейс.

## Бележки

- Цените в `demo` са примерни и не са реални оферти.
- Няма автоматично сваляне на цени от уебсайтове — цените се въвеждат ръчно или от CSV.
- Всички данни са локални; системата не изпраща нищо навън.
